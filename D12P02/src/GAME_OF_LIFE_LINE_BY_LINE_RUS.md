# `game_of_life.c` — построчное объяснение

Ниже разбор текущего файла `D12P02/src/game_of_life.c` по строкам (смысл каждой строки или небольшой группы строк).

## 1) Подключения и константы

- **1** — подключение `ncurses` для рисования в терминале и чтения клавиш.
- **2** — подключение `stdio` для работы с `FILE`, `fopen`, `fscanf`.
- **4** — высота поля `ROWS = 25`.
- **5** — ширина поля `COLS = 80`.
- **6** — минимальная задержка кадра (ускорение ограничено).
- **7** — максимальная задержка кадра (замедление ограничено).
- **8** — шаг изменения скорости при нажатии A/Z.

## 2) Инициализация поля

### `fill_default` (10–16)
- **10** — объявление функции очистки поля.
- **11–15** — двойной цикл по всем клеткам.
- **13** — каждая клетка ставится в `0` (мертвая).

## 3) Режим запуска (mode)

### `parse_mode` (18–26)
- **18** — функция разбора аргумента запуска.
- **19** — `mode = 0` как значение «невалидно».
- **20–24** — проверка, что аргумент есть и это ровно один символ `'1'..'6'`.
- **22** — перевод символа в число.
- **25** — единственный `return`.

### `preset_path` (28–42)
- **28** — функция возвращает основной путь к файлу пресета.
- **29** — по умолчанию путь `NULL`.
- **30–40** — соответствие mode→файл:
  - 2 → `cow.txt`
  - 3 → `gun_gosper.txt`
  - 4 → `gun_simple.txt`
  - 5 → `agar.txt`
  - 6 → `ship_new.txt`
- **41** — вернуть найденный путь.

### `preset_fallback_path` (44–58)
- **44** — запасной путь, если запуск не из `D12P02/src`.
- **46–56** — те же пресеты, но с префиксом `./D12P02/src/presets/...`.
- **57** — вернуть fallback-путь.

## 4) Чтение поля из потока/файла

### `read_field_stream` (60–70)
- **61** — перед чтением поле обнуляется.
- **62–69** — чтение матрицы 25x80 из потока.
- **64** — временная переменная для числа.
- **65** — если число успешно прочитано, используем его.
- **66** — любое ненулевое значение нормализуется в `1`.

### `set_demo_glider` (72–81)
- **72** — аварийный шаблон, если пресет не открылся.
- **73–74** — центр поля.
- **75** — очистка.
- **76–80** — ставим 5 клеток «глайдера».

### `load_preset` (83–99)
- **84** — основной путь.
- **85** — fallback-путь.
- **86** — указатель файла.
- **87–89** — пробуем открыть основной путь.
- **90–92** — если не получилось, пробуем fallback.
- **93–95** — если файл открыт, читаем матрицу и закрываем файл.
- **96–98** — если оба пути не сработали, ставим demo-глайдер.

## 5) Тороидальные границы

### `wrap_row` (101–110)
- **102** — копия индекса строки.
- **103–105** — если вышли выше поля, перенос в конец.
- **106–108** — если вышли ниже поля, перенос в начало.
- **109** — вернуть корректный индекс.

### `wrap_col` (112–121)
- То же самое для столбца.

## 6) Логика жизни

### `neighbors_count` (123–135)
- **124** — счётчик соседей.
- **125–126** — обход смещений `-1..1` по строке/столбцу.
- **127** — пропускаем саму клетку `(0,0)`.
- **128–129** — считаем индекс соседа с учетом тора.
- **130** — добавляем значение соседа (`0`/`1`).
- **134** — вернуть число соседей.

### `next_cell` (137–145)
- **138** — значение клетки в следующем поколении.
- **139–143** — правила Conway:
  - живая выживает при 2 или 3 соседях;
  - мертвая рождается при 3 соседях.
- **144** — вернуть новое состояние.

### `evolve` (147–154)
- **148–153** — пройти по всему полю и вычислить новое поле `next`.
- **150–151** — для каждой клетки: соседи → новое значение.

### `copy_field` (156–162)
- Копирует `next` обратно в текущее поле `field`.

## 7) Интерфейс и управление

### `draw_field` (164–173)
- **165–169** — рисуем все клетки:
  - `#` для живой,
  - `.` для мертвой.
- **170–171** — строка статуса: управление, mode, gen, delay.
- **172** — обновить экран `refresh()`.

### `process_key` (175–187)
- **176–179** — `A/a`: ускорить (уменьшить задержку до лимита).
- **180–183** — `Z/z`: замедлить (увеличить задержку до лимита).
- **184–185** — `Space`: остановить игру.

### `run_game` (189–203)
- **190** — буфер следующего поколения.
- **191** — флаг работы цикла.
- **192** — стартовая задержка 200 мс.
- **193** — номер поколения.
- **194** — установить таймаут `getch`.
- **195–202** — игровой цикл:
  1. рисуем текущее поле,
  2. читаем и обрабатываем клавишу,
  3. обновляем таймаут,
  4. считаем следующее поколение,
  5. копируем его в текущее,
  6. увеличиваем `generation`.

## 8) `main`

### `main` (205–227)
- **206** — массив поля 25x80.
- **207** — дефолтный mode = 3.
- **208–210** — если передан аргумент, пытаемся распарсить mode.
- **211–213** — mode `1`: читаем поле из `stdin`.
- **214–218** — mode `2..6`: грузим пресет (невалидный mode → `2`).
- **219–223** — настройка `ncurses`:
  - `initscr`, `noecho`, `cbreak`, `curs_set(0)`, `keypad`.
- **224** — запуск основного цикла.
- **225** — завершение `ncurses`.
- **226** — код успешного завершения.

## Быстрый запуск

Из папки `D12P02/src`:

```bash
gcc -Wall -Wextra -Werror game_of_life.c -lncurses -o game_of_life
./game_of_life 2
```

Управление в игре:
- `A` — быстрее
- `Z` — медленнее
- `Space` — выход
