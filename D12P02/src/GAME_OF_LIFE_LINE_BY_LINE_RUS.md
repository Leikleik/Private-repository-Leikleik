# `game_of_life.c` — построчное объяснение

Ниже разбор текущего файла `D12P02/src/game_of_life.c` по строкам (смысл каждой строки или небольшой группы строк).

## 1) Директивы препроцессора

- **1–2** — `#include` для `ncurses` и `stdio`.
- **4–6** — размеры поля и параметры скорости.

## 2) Прототипы функций

- **8–15** — объявлены все функции, реализованные ниже.

## 3) `main`

- **17–63** — главный цикл:
  - выбор пресета через `read_mode_from_user`,
  - открытие файла в `switch`,
  - чтение поля,
  - запуск `ncurses`,
  - цикл отрисовки и обработки ввода.

## 4) Функции

### `initialize_field` (65–79)
- читает матрицу 25x80 из `stdin` и нормализует значения в `0/1`.

### `print_menu` (81–83)
- выводит подсказку по управлению.

### `print_field` (85–92)
- выводит поле в терминал (`#` для живых, `.` для мёртвых).

### `count_neighbors` (94–107)
- считает соседей с тороидальной топологией.

### `calculate_next_generation` (109–129)
- вычисляет `next` и копирует его обратно в `current`.

### `get_user_input` (131–139)
- получает символ через `getch()` и возвращает `0`, если ввода нет.

### `read_mode_from_user` (141–161)
- запрашивает число `1..5`, пока не введено корректное.

### `process_input` (163–185)
- `A/Z` меняют скорость, `Space` завершает игру.

---

## Быстрый запуск

Из папки `D12P02/src`:

```bash
gcc -Wall -Wextra -Werror game_of_life.c -lncurses -o game_of_life
./game_of_life
```
