# `game_of_life.c` — построчное объяснение

Ниже разбор текущего файла `D12P02/src/game_of_life.c` по строкам (смысл каждой строки или небольшой группы строк).

## 1) Подключения и константы

- **1** — подключение `ncurses` для рисования в терминале и чтения клавиш.
- **2** — подключение `stdio` для ввода/вывода.
- **4** — высота поля `ROWS = 25`.
- **5** — ширина поля `COLS = 80`.
- **6** — минимальная задержка кадра.
- **7** — максимальная задержка кадра.
- **8** — шаг изменения скорости.

## 2) Инициализация поля

### `fill_default` (10–16)
- **10** — объявление функции очистки поля.
- **11–15** — двойной цикл по всем клеткам.
- **13** — каждая клетка ставится в `0` (мертвая).

## 3) Ввод режима

### `read_mode_from_user` (18–37)
- **18** — функция запрашивает номер режима у пользователя.
- **19–21** — `mode` и флаг `valid` для цикла запроса.
- **22** — приглашение ввести число от 1 до 5.
- **23–31** — проверка корректности и вывод ошибки при неверном вводе.
- **32–35** — очистка остатка строки после ввода.
- **37** — единственный `return`.

### `change_stream` (40–51)
- **40–50** — переключение `stdin` на один из файлов `./presets/1.txt` … `./presets/5.txt` через `freopen`.

## 4) Чтение поля

### `read_field` (53–63)
- **54** — очистка поля перед чтением.
- **55–62** — чтение матрицы 25x80 из `stdin`.
- **57–59** — любое ненулевое значение превращается в `1`.

## 5) Тороидальные границы

### `wrap_row` (65–74)
- **66** — копия индекса строки.
- **67–69** — если вышли выше поля, перенос в конец.
- **70–72** — если вышли ниже поля, перенос в начало.
- **73** — вернуть корректный индекс.

### `wrap_col` (76–85)
- То же самое для столбца.

## 6) Логика жизни

### `neighbors_count` (87–99)
- **88** — счётчик соседей.
- **89–90** — перебор смещений `-1..1`.
- **91** — исключаем саму клетку.
- **92–94** — считаем индекс соседа с учетом тора и суммируем.
- **98** — вернуть число соседей.

### `next_cell` (101–109)
- **102** — значение клетки в следующем поколении.
- **103–107** — правила Conway (выживание 2/3, рождение 3).
- **108** — вернуть новое состояние.

### `evolve` (111–118)
- **112–117** — проход по всему полю и вычисление нового `next`.

### `copy_field` (120–126)
- Копирует `next` обратно в `field`.

## 7) Интерфейс и управление

### `draw_field` (128–137)
- **129–133** — рисуем клетки `#` и `.`.
- **134–135** — строка статуса: управление, mode, gen, delay.
- **136** — `refresh()`.

### `process_key` (139–151)
- **140–143** — `A/a`: ускорить.
- **144–147** — `Z/z`: замедлить.
- **148–149** — `Space`: остановить игру.

### `run_game` (153–167)
- **154–158** — инициализация буфера, задержки и поколения.
- **159–166** — основной цикл: рисование, ввод, эволюция.

## 8) `main`

### `main` (169–181)
- **170** — массив поля 25x80.
- **171** — чтение корректного номера режима `1..5`.
- **172** — переключение `stdin` на выбранный пресет.
- **173** — чтение матрицы из `stdin`.
- **174–179** — настройка `ncurses` и запуск игры.
- **180** — `endwin()`.
- **181** — код успешного завершения.

---

## Быстрый запуск

Из папки `D12P02/src`:

```bash
gcc -Wall -Wextra -Werror game_of_life.c -lncurses -o game_of_life
./game_of_life
```

Управление в игре:
- `A` — быстрее
- `Z` — медленнее
- `Space` — выход
