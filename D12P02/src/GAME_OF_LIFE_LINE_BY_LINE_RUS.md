# `game_of_life.c` — построчное объяснение

Ниже разбор текущего файла `D12P02/src/game_of_life.c` по строкам (смысл каждой строки или небольшой группы строк).

## 1) Подключения и константы

- **1** — подключение заголовка `game_of_life.h`, где лежат константы и прототипы.
- В `game_of_life.h` определены размеры поля и параметры задержки:
  - `ROWS = 25`, `COLS = 80`
  - `MIN_DELAY`, `MAX_DELAY`, `DELAY_STEP`

## 2) Инициализация поля

### `fill_default` (10–16)
- **10** — объявление функции очистки поля.
- **11–15** — двойной цикл по всем клеткам.
- **13** — каждая клетка ставится в `0` (мертвая).

## 3) Ввод режима

### `read_mode_from_user` (18–37)
- **18** — функция запрашивает номер режима у пользователя.
- **19–21** — `mode` и флаг `valid` для цикла запроса.
- **22** — приглашение ввести число от 1 до 5.
- **23–31** — проверка корректности и вывод ошибки при неверном вводе.
- **32–35** — очистка остатка строки после ввода.
- **37** — единственный `return`.

### `change_stream` (40–51)
- **40–50** — переключение `stdin` на один из файлов `./presets/1.txt` … `./presets/5.txt` через `freopen`.

### `restore_stdin` (53–55)
- **53** — возвращает ввод обратно в терминал (`/dev/tty`), чтобы клавиши в `ncurses` работали.

## 4) Чтение поля

### `read_field` (57–67)
- **58** — очистка поля перед чтением.
- **59–66** — чтение матрицы 25x80 из `stdin`.
- **61–63** — любое ненулевое значение превращается в `1`.

## 5) Тороидальные границы

### `wrap_row` (69–78)
- **70** — копия индекса строки.
- **71–73** — если вышли выше поля, перенос в конец.
- **74–76** — если вышли ниже поля, перенос в начало.
- **77** — вернуть корректный индекс.

### `wrap_col` (80–89)
- То же самое для столбца.

## 6) Логика жизни

### `neighbors_count` (91–103)
- **92** — счётчик соседей.
- **93–94** — перебор смещений `-1..1`.
- **95** — исключаем саму клетку.
- **96–98** — считаем индекс соседа с учетом тора и суммируем.
- **102** — вернуть число соседей.

### `next_cell` (105–113)
- **106** — значение клетки в следующем поколении.
- **107–111** — правила Conway (выживание 2/3, рождение 3).
- **112** — вернуть новое состояние.

### `evolve` (115–122)
- **116–121** — проход по всему полю и вычисление нового `next`.

### `copy_field` (124–130)
- Копирует `next` обратно в `field`.

## 7) Интерфейс и управление

### `draw_field` (131–140)
- **131** — очистка экрана `clear()` перед перерисовкой.
- **132–136** — рисуем клетки `#` и пробелы.
- **137–138** — строка статуса: управление, mode, gen, delay.
- **139** — `refresh()`.

### `process_input` (142–154)
- **143–146** — `A/a`: ускорить.
- **147–150** — `Z/z`: замедлить.
- **151–152** — `Space`: остановить игру.

### `run_game` (156–169)
- **157–160** — инициализация буфера, задержки и поколения.
- **161–168** — основной цикл: рисование, ввод, эволюция.

## 8) `main`

### `main` (172–186)
- **173** — массив поля 25x80.
- **174** — чтение корректного номера режима `1..5`.
- **175** — переключение `stdin` на выбранный пресет.
- **176** — чтение матрицы из `stdin`.
- **177** — возвращаем `stdin` обратно в терминал.
- **178–184** — настройка `ncurses`, включение неблокирующего ввода и запуск игры.
- **185** — `endwin()`.
- **186** — код успешного завершения.

## Быстрый запуск

Из папки `D12P02/src`:

```bash
gcc -Wall -Wextra -Werror game_of_life.c -lncurses -o game_of_life
./game_of_life
```

Управление в игре:
- `A` — быстрее
- `Z` — медленнее
- `Space` — выход
