# `game_of_life.c` — построчное объяснение

Ниже разбор текущего файла `D12P02/src/game_of_life.c` по строкам (смысл каждой строки или небольшой группы строк).

## 1) Директивы препроцессора

- **1–2** — `#include` для `ncurses` и `stdio`.
- **4–5** — константы размеров поля `ROWS` и `COLS`.

## 2) Прототипы функций

- **7–15** — прототипы всех функций, реализованных ниже.

## 3) `main`

- **17–40** — главный цикл:
  - объявляет `field` и `next_gen`,
  - получает номер пресета,
  - читает поле из файла,
  - запускает `ncurses`,
  - показывает меню и поле,
  - принимает команду `n` или `q`.

## 4) Функции логики и ввода

### `initialize_field` (42–57)
- читает матрицу 25x80 из `stdin` и нормализует значения в `0/1`.

### `print_field` (59–67)
- выводит поле в терминал (`#` для живых, `.` для мёртвых).

### `count_neighbors` (69–82)
- считает соседей с тороидальной топологией.

### `calculate_next_generation` (84–104)
- вычисляет `next` и копирует его обратно в `current`.

### `get_user_input` (106–110)
- получает символ через `getch()` и очищает буфер.

### `print_menu` (112–114)
- выводит меню команд.

### `read_mode_from_user` (116–136)
- запрашивает число `1..5`, пока не введено корректное.

### `change_stream` (138–150)
- перенаправляет `stdin` на файл `./presets/1.txt` … `./presets/5.txt`.

### `restore_stdin` (152–154)
- возвращает `stdin` обратно в терминал (`/dev/tty`).

---

## Быстрый запуск

Из папки `D12P02/src`:

```bash
gcc -Wall -Wextra -Werror game_of_life.c -lncurses -o game_of_life
./game_of_life
```

Управление в игре:
- `n` — следующее поколение
- `q` — выход
